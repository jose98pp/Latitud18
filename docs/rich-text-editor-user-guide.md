# Guía de Usuario - Editor de Texto Enriquecido

## Introducción

El Editor de Texto Enriquecido es una herramienta avanzada que permite crear y editar contenido con formato HTML de manera visual e intuitiva. Esta guía le ayudará a aprovechar al máximo todas las funcionalidades disponibles.

## Ubicación del Editor

El editor está disponible en las siguientes secciones del panel de administración:

- **Noticias**: Al crear o editar noticias (campo "Contenido")
- **Categorías**: Al crear o editar categorías (campo "Descripción")

## Interfaz del Editor

### Barra de Herramientas

La barra de herramientas contiene todas las opciones de formato disponibles:

#### Grupo 1: Deshacer/Rehacer
- **↶ Deshacer**: Revierte el último cambio realizado
- **↷ Rehacer**: Restaura el último cambio deshecho

#### Grupo 2: Formato de Texto
- **𝐁 Negrita**: Aplica formato en negrita al texto seleccionado
- **𝑰 Cursiva**: Aplica formato en cursiva al texto seleccionado
- **U̲ Subrayado**: Subraya el texto seleccionado
- **S̶ Tachado**: Aplica formato tachado al texto seleccionado

#### Grupo 3: Tamaño de Fuente
- **Selector de Tamaño**: Permite cambiar el tamaño del texto
  - Pequeño (12px)
  - Normal (16px)
  - Mediano (20px)
  - Grande (24px)
  - Muy Grande (32px)

#### Grupo 4: Color de Texto
- **🎨 Selector de Color**: Abre una paleta de colores para cambiar el color del texto

#### Grupo 5: Alineación
- **⟮⟮ Izquierda**: Alinea el texto a la izquierda
- **☰ Centro**: Centra el texto
- **⟯⟯ Derecha**: Alinea el texto a la derecha
- **⟮☰⟯ Justificar**: Justifica el texto

#### Grupo 6: Listas
- **•≡ Lista con Viñetas**: Crea una lista con viñetas
- **1. Lista Numerada**: Crea una lista numerada

#### Grupo 7: Sangría
- **← Disminuir**: Reduce la sangría del párrafo
- **→ Aumentar**: Aumenta la sangría del párrafo

#### Grupo 8: Multimedia
- **📷 Subir Imagen**: Permite subir e insertar imágenes en el contenido

#### Grupo 9: Vista
- **👁 Vista Previa**: Alterna entre modo edición y vista previa

### Área de Edición

El área principal donde se escribe y edita el contenido. Soporta:
- Escritura directa
- Formato aplicado mediante la barra de herramientas
- Arrastrar y soltar texto
- Pegado de contenido desde otras aplicaciones

## Funcionalidades Principales

### 1. Formato de Texto

#### Aplicar Formato
1. Seleccione el texto que desea formatear
2. Haga clic en el botón de formato deseado en la barra de herramientas
3. El formato se aplicará inmediatamente

#### Cambiar Color de Texto
1. Seleccione el texto
2. Haga clic en el botón de color (🎨)
3. Seleccione el color deseado de la paleta
4. El color se aplicará al texto seleccionado

#### Cambiar Tamaño de Fuente
1. Seleccione el texto
2. Use el selector de tamaño de fuente
3. Elija el tamaño deseado

### 2. Listas

#### Crear Lista con Viñetas
1. Coloque el cursor donde desea la lista
2. Haga clic en el botón de lista con viñetas (•≡)
3. Escriba el primer elemento
4. Presione Enter para crear un nuevo elemento
5. Presione Enter dos veces para finalizar la lista

#### Crear Lista Numerada
1. Coloque el cursor donde desea la lista
2. Haga clic en el botón de lista numerada (1.)
3. Escriba el primer elemento
4. Presione Enter para crear un nuevo elemento
5. Presione Enter dos veces para finalizar la lista

### 3. Subida de Imágenes

#### Requisitos de Imagen
- **Formatos soportados**: JPG, PNG, GIF, WebP
- **Tamaño máximo**: 5 MB por imagen
- **Recomendaciones**: Use imágenes optimizadas para web

#### Proceso de Subida
1. Haga clic en el botón de imagen (📷)
2. Seleccione la imagen desde su computadora
3. Espere a que se complete la subida (verá un indicador de progreso)
4. La imagen se insertará automáticamente en el contenido

#### Indicadores de Estado
- **⏳ Subiendo**: La imagen se está procesando
- **✅ Éxito**: La imagen se subió correctamente
- **❌ Error**: Hubo un problema con la subida

### 4. Atajos de Teclado

#### Formato de Texto
- **Ctrl + B**: Negrita
- **Ctrl + I**: Cursiva
- **Ctrl + U**: Subrayado
- **Ctrl + Z**: Deshacer
- **Ctrl + Y**: Rehacer

#### Acciones
- **Ctrl + S**: Guardar formulario
- **Ctrl + Shift + P**: Alternar vista previa
- **Enter**: Nuevo párrafo
- **Shift + Enter**: Salto de línea

### 5. Guardado Automático

El editor incluye una función de guardado automático que:
- Guarda el contenido cada 3 segundos
- Muestra la hora del último guardado en la consola
- Funciona en segundo plano sin interrumpir la edición

### 6. Vista Previa

La función de vista previa permite:
- Ver cómo se verá el contenido final
- Verificar el formato antes de guardar
- Alternar fácilmente entre edición y vista previa

## Mejores Prácticas

### Estructura del Contenido
1. **Use encabezados**: Organice el contenido con títulos y subtítulos
2. **Párrafos cortos**: Mantenga los párrafos concisos y legibles
3. **Listas**: Use listas para información organizada
4. **Imágenes**: Incluya imágenes relevantes para enriquecer el contenido

### Formato
1. **Consistencia**: Mantenga un formato consistente en todo el documento
2. **Moderación**: No abuse de los formatos (negrita, cursiva, colores)
3. **Legibilidad**: Priorice la legibilidad sobre la decoración

### Imágenes
1. **Optimización**: Use imágenes optimizadas para reducir el tiempo de carga
2. **Relevancia**: Solo incluya imágenes que aporten valor al contenido
3. **Tamaño**: Respete el límite de 5 MB por imagen

## Solución de Problemas

### El Editor No Carga

**Síntomas**: Aparece un área de texto simple en lugar del editor avanzado

**Soluciones**:
1. Verifique su conexión a internet
2. Actualice la página (F5)
3. Limpie la caché del navegador
4. Intente con otro navegador

### Error al Subir Imágenes

**Síntomas**: Mensaje de error al intentar subir una imagen

**Posibles Causas y Soluciones**:
1. **Archivo muy grande**: Reduzca el tamaño de la imagen (máximo 5 MB)
2. **Formato no soportado**: Use JPG, PNG, GIF o WebP
3. **Conexión lenta**: Espere más tiempo o intente con una conexión más rápida
4. **Espacio insuficiente**: Contacte al administrador del sistema

### Contenido No Se Guarda

**Síntomas**: Los cambios se pierden al recargar la página

**Soluciones**:
1. Asegúrese de hacer clic en "Guardar" antes de salir
2. Verifique que el contenido no esté vacío
3. Use Ctrl+S para guardar rápidamente
4. Verifique su conexión a internet

### Formato Se Pierde

**Síntomas**: El formato desaparece después de guardar

**Soluciones**:
1. Evite copiar y pegar desde programas como Word
2. Use las herramientas del editor para aplicar formato
3. Verifique en vista previa antes de guardar

## Navegadores Soportados

El editor funciona correctamente en:
- **Chrome** (versión 80+)
- **Firefox** (versión 75+)
- **Safari** (versión 13+)
- **Edge** (versión 80+)

## Limitaciones

### Contenido
- **Longitud máxima**: 50,000 caracteres de texto
- **Imágenes**: Máximo 5 MB por imagen
- **Formatos**: Solo se permiten ciertos elementos HTML por seguridad

### Funcionalidad
- **Tablas**: No soportadas actualmente
- **Videos**: Solo se pueden insertar mediante código HTML
- **Archivos**: Solo se pueden subir imágenes

## Contacto y Soporte

Si experimenta problemas no cubiertos en esta guía:
1. Documente el problema (capturas de pantalla si es posible)
2. Anote los pasos que llevaron al problema
3. Contacte al administrador del sistema
4. Proporcione información sobre su navegador y sistema operativo
